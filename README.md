# Chess Isometry Rework 1.0

Изометрическая шахматная игра с красивой анимацией, мультиплеером и голосовым чатом.

## Особенности

- 🎨 **Изометрическая проекция** - уникальный вид шахматной доски
- ⚡ **Анимированные частицы** - эффекты при съедании фигур
- 🎮 **Мультиплеер** - играйте с друзьями по локальной сети или VPN
- 🎤 **Голосовой чат** - общайтесь во время игры
- 🎵 **Музыка и звуки** - атмосферное сопровождение
- ✨ **Splash-тексты** - случайные забавные фразы как в Minecraft
- ♟️ **Полная валидация правил** - все шахматные правила работают корректно

## Установка

### Требования
- Python 3.7 или выше
- Windows 10/11 (протестировано)

### Шаг 1: Клонирование репозитория
```bash
git clone https://github.com/yourusername/Chess-isometry.git
cd Chess-isometry
```

### Шаг 2: Установка зависимостей
```bash
pip install -r requirements.txt
```

**Важно для Windows (голосовой чат):**
Если возникают проблемы с PyAudio:
```bash
pip install pipwin
pipwin install pyaudio
```

### Шаг 3: Запуск игры
```bash
python Chess.pyw
```

## Управление

### В игре
- **ЛКМ** - выбрать фигуру / сделать ход
- **ESC** - отменить выбор
- **F11** - полноэкранный режим
- **F3** - режим отладки

### В мультиплеере
- **M** - включить/выключить микрофон
- **ESC** - выход в меню

## Мультиплеер

### Создание игры (Хост)
1. Главное меню → **MULTIPLAYER**
2. Настройте профиль (никнейм, аватар)
3. **СОЗДАТЬ ИГРУ** → **ЗАПУСТИТЬ ХОСТ**
4. Скопируйте IP адрес и отправьте другу
5. Дождитесь подключения → **НАЧАТЬ ИГРУ**

### Присоединение к игре (Клиент)
1. Главное меню → **MULTIPLAYER**
2. Настройте профиль (никнейм, аватар)
3. **ПРИСОЕДИНИТЬСЯ**
4. Введите IP адрес хоста → **ПОДКЛЮЧИТЬСЯ**
5. Дождитесь начала игры

### Голосовой чат
- Запускается автоматически при подключении
- Клавиша **M** - включить/выключить микрофон
- Статус отображается в левом нижнем углу

### Игра через VPN
1. Используйте любой VPN (Radmir VPN, Hamachi и др.)
2. Подключитесь к одной сети
3. Следуйте инструкциям выше

## Устранение неполадок

### Игра не запускается
- Убедитесь что Python 3.7+ установлен
- Проверьте установку зависимостей
- Проверьте наличие папки `data/`

### Проблемы с голосовым чатом
- Проверьте подключение микрофона
- Разрешите доступ к микрофону в настройках Windows
- Убедитесь что PyAudio установлен корректно

### Проблемы с подключением
- Проверьте что оба игрока в одной сети
- Убедитесь что порт 12345 не заблокирован
- Проверьте правильность IP адреса

### Аватары не отображаются
- Проверьте папку `data/avatars/`
- Удалите `data/player_profile.json` и перезапустите
